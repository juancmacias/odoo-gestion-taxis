# Módulos para Odoo 19.0

![Odoo Version](https://img.shields.io/badge/Odoo-19.0-875A7B?style=flat-square)
![License](https://img.shields.io/badge/License-LGPL--3-blue?style=flat-square)

Colección de módulos personalizados para Odoo 19.0

## Módulos incluidos

### 🚕 Gestión de Taxis PRO
Sistema completo para la gestión de flotas de taxis, conductores, tarifas y viajes.

📖 **Documentación completa**: [Ver artículo](https://juancarlosmacias.es/article/modulo-de-gestion-de-flotas-de-taxis-con-odoo)

### 🎮 Word Search Gamification
Módulo de gamificación con juego de sopa de letras interactivo, tabla de clasificación y gestión de intentos

## Instalación

```bash
# Clonar el repositorio en tu carpeta de addons de Odoo
cd /path/to/odoo/addons
git clone https://github.com/juancmacias/odoo-module.git#19.0
```

## Uso

1. Reiniciar el servidor Odoo
2. Actualizar la lista de aplicaciones
3. Buscar e instalar el/los modulos
