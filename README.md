Repositorio de módulos para Odoo 19.0

## Módulos incluidos

### 🚕 Gestión de Taxis PRO
Sistema completo para la gestión de flotas de taxis, conductores, tarifas y viajes.

**Características:**
- Gestión de vehículos (taxis)
- Gestión de conductores
- Sistema de tarifas personalizables
- Control completo de viajes
- Cálculo automático de precios

📖 **Documentación completa**: [Ver artículo](https://juancarlosmacias.es/article/modulo-de-gestion-de-flotas-de-taxis-con-odoo)

## Instalación

```bash
# Clonar el repositorio en tu carpeta de addons de Odoo
cd /path/to/odoo/addons
git clone https://github.com/juancmacias/odoo-gestion-taxis.git#19.0
```

## Uso

1. Reiniciar el servidor Odoo
2. Actualizar la lista de aplicaciones
3. Buscar e instalar "Gestión de Taxis PRO"
