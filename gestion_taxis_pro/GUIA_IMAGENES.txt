│ 📸 CÓMO TOMAR LAS CAPTURAS DE PANTALLA:                                  │
└───────────────────────────────────────────────────────────────────────────┘

   Paso 1: Instala el módulo en Odoo
   Paso 2: Crea datos de prueba:
           - 3-5 taxis
           - 3-5 conductores
           - 2-3 tarifas
           - 4-6 viajes (con diferentes estados)
   
   Paso 3: Abre cada vista en Odoo
   Paso 4: Presiona Windows + Shift + S para capturar
           o usa la herramienta Recortes de Windows
   
   Paso 5: Guarda cada captura con el nombre correcto en:
           e:\odoo-19.0\addons\gestion_taxis_pro\static\description\
