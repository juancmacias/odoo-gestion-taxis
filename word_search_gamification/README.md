# Odoo Word Search Gamification

Módulo de gamificación empresarial con sopas de letras para Odoo 19.

## Características

- 🎮 Gestión de juegos de sopa de letras
- 📊 Tres niveles de dificultad (Easy, Medium, Hard)
- 🎯 Tamaño de cuadrícula configurable
- 👥 Integración con módulo de Recursos Humanos

## Instalación

1. Copia la carpeta `odoo_word_search_gamification` en tu directorio de addons de Odoo
2. Actualiza la lista de aplicaciones
3. Instala el módulo "Odoo Word Search Gamification"

## Uso

Accede al menú **Gamification > Games** para crear y gestionar tus juegos de sopa de letras.
